# 05 · Python Mini Projects

**Автор:** Ира Улмаскулова  
**GitHub:** [ulmaskulovaira-collab](https://github.com/ulmaskulovaira-collab)

Небольшие учебные проекты на Python.  
Показывают базовые навыки программирования, которые полезны для написания автотестов (логика, циклы, функции, обработка ошибок).

---

## Проекты

| № | Папка | Описание | Основные темы |
|---|-------|----------|---------------|
| 01 | `01_number_guessing` | Игра «Угадай число» | `random`, циклы, условия, обработка ошибок |
| 02 | `02_dice_roller` | Симулятор кубика (ASCII) | `random`, словари |
| 03 | `03_password_generator` | Генератор паролей | `random`, `string` |
| 04 | `04_email_slicer` | Разделение email | строки, `split` |
| 05 | `05_caesar_cipher` | Шифр Цезаря | функции, `ord`/`chr` |
| 06 | `06_calculator` | Калькулятор выражений | `eval`, обработка исключений |

---

## Как запустить

```bash
cd 01_number_guessing   # или любая другая папка
python main.py
```

Все проекты работают **только на стандартной библиотеке Python** (ничего устанавливать не нужно).
