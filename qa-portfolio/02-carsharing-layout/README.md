# Проект 2. Тестирование вёрстки формы бронирования каршеринга

**Спринт:** 3  
**Тип:** UI-тестирование + функциональные проверки формы бронирования

## Что сделано

- Чек-лист на вёрстку исходного состояния формы «Яндекс Маршрут» / каршеринг
- Проверки в двух браузерах и разрешениях:
  - Яндекс Браузер 26.4.2 / Win11 / 800×600
  - Firefox 138.0.1 / Win11 / 1920×1080
- Покрытие блоков:
  - Исходное состояние формы
  - Тариф «Роскошный»
  - Добавление прав
  - Способ оплаты
  - Требования к заказу
  - Кнопка «Забронировать»
  - Модальные окна бронирования и отмены
  - Карта (иконки автомобилей)
- Оформленные баг-репорты с приоритетами (блокирующий, критический, средний, низкий)

## Артефакт

## Примеры найденных дефектов

- Надпись «Учебный режим» расположена некорректно
- Не выбирается ближайшая машина автоматически
- При выборе тарифа на карте показываются авто всех тарифов
- Нет зелёной галочки / красного крестика после верификации прав
- Кнопка отмены бронирования не реагирует (блокирующий)
- Таймер бесплатного ожидания не переключается на платное время
- Поле «Код» / «Номер карты» принимают буквы, спецсимволы, неправильную длину
- После добавления карты не отображаются последние 4 цифры
