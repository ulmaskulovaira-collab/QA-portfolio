# Проект 3. Регрессионное тестирование «Место» (Mesto)

**Когорта:** 55  
**Тип:** регрессионное тестирование

**Стенд:** https://code.s3.yandex.net/qa/files/mesto/index.html  
**Требования:** https://code.s3.yandex.net/qa-automation-engineer/trebovaniya_mesto.pdf

## Что сделано

Регрессионный прогон ключевых сценариев редактирования профиля:

- Открытие / закрытие окна редактирования
- Отображение текущих данных в полях «Имя» и «Занятие»
- Валидация длины (минимум / максимум символов)
- Активность кнопки «Сохранить»
- Обработка пробелов

## Артефакт

| Файл | Описание |
|------|----------|
| `report.pdf` | PDF-отчёт о выполненной работе |
| `regression-checklist.xlsx` | Чек-лист / тест-кейсы регресса + статусы + ссылки на баг-репорты |

## Примеры найденных дефектов

- В полях редактирования не подтягивается текст с главной страницы
- Нет сообщения об ошибке при недопустимом количестве символов
- Кнопка «Сохранить» остаётся активной при пустых полях
- Проблемы с автоудалением пробелов при сохранении

## Навыки

- Регрессионное тестирование
- Работа с готовым стендом по требованиям
- Фиксация статусов (Passed / Failed / Blocked)
