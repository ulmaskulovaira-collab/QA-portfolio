# Шаблон отчета по проверке

## Название проверки

Регрессионная проверка рабочего сценария пользователя.

## Дата

Указать дату проверки.

## Окружение

- Стенд: тестовый / локальный
- Браузер: указать браузер
- Роль: обезличенная роль
- Данные: тестовые обезличенные данные

## Что проверялось

Проверялись основные пользовательские сценарии:

- доступ к разделу;
- отображение списка объектов;
- открытие карточки объекта;
- выполнение основного действия;
- валидации;
- ограничения;
- отображение результата;
- история действий.

## Что подтвердилось

- Пользователь с нужной ролью может открыть раздел.
- Список объектов отображается.
- Карточка объекта открывается.
- Основное действие доступно при подходящих условиях.
- Часть валидаций работает корректно.
- Результат действия фиксируется в истории.

## Что не подтвердилось или требует внимания

- В отдельных сценариях результат может отображаться не во всех связанных местах.
- Для некоторых проверок нужно заранее подготовить тестовые данные.
- Сообщения об ошибках не всегда достаточно понятны пользователю.

## Ограничения проверки

- Проверка выполнена на тестовом окружении.
- Интеграционные сценарии проверялись только в рамках доступных данных.
- Реальные данные и внутренние детали не раскрываются.

## Итог

Статус: пройдено / пройдено с замечаниями / не пройдено.

Комментарий:

```text
Основной сценарий работает, но есть замечания по отображению результата и подготовке данных для отдельных проверок.
```

## Рекомендации

- Заранее готовить тестовые данные для каждого сценария.
- Отдельно проверять роли и доступы.
- После действия сверять результат не только в интерфейсе, но и в истории.
- Фиксировать ограничения проверки в отчете.
