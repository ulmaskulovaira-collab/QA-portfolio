# 01. Ручное тестирование интернет-магазина SauceDemo

## Цель

Подготовить набор проверок для ключевого пользовательского пути: вход → выбор товара → корзина → оформление заказа. Проект показывает работу с требованиями, тест-дизайном и документацией для web-приложения.

**Тестовая среда:** [SauceDemo](https://www.saucedemo.com/) · web · Chrome/Firefox · ручное тестирование.

## Объём проверки

| Входит в объём | Не входит в объём |
| --- | --- |
| авторизация, каталог, сортировка, карточки товаров, корзина, checkout | нагрузочное тестирование, платёжный шлюз, безопасность production-среды |

## Тест-план

| Поле | Значение |
| --- | --- |
| Цель | проверить, что пользователь может оформить заказ без потери товара или данных |
| Подход | smoke перед началом, затем функциональные, негативные и граничные сценарии |
| Риски | некорректные данные в форме, неверная сумма, потеря корзины, ошибки сортировки |
| Критерий завершения | выполнены все запланированные тест-кейсы; блокирующие дефекты отсутствуют либо согласованы |

## Быстрый чек-лист

- [x] Вход с корректными данными открывает каталог.
- [x] Неверный логин или пароль не дают войти и показывают понятное сообщение.
- [x] Товар добавляется и удаляется из корзины.
- [x] Счётчик корзины соответствует количеству выбранных товаров.
- [x] Сортировка меняет порядок товаров согласно выбранному варианту.
- [x] Стоимость товаров и итоговая сумма отображаются корректно.
- [x] Обязательные поля checkout валидируются.
- [x] После успешного заказа открывается подтверждение.

## Тест-кейсы

| ID | Сценарий | Приоритет | Ожидаемый результат |
| --- | --- | --- | --- |
| TC-WEB-001 | Вход с валидными учётными данными | High | Пользователь попадает на страницу каталога |
| TC-WEB-002 | Вход с неверным паролем | High | Вход не выполнен, показано сообщение об ошибке |
| TC-WEB-003 | Добавление товара из каталога | High | Товар появляется в корзине, счётчик увеличивается |
| TC-WEB-004 | Удаление товара из корзины | High | Товар и счётчик обновляются корректно |
| TC-WEB-005 | Сортировка по цене | Medium | Порядок товаров соответствует выбранному направлению |
| TC-WEB-006 | Оформление заказа с валидными данными | Critical | Заказ подтверждён, пользователь видит финальный экран |
| TC-WEB-007 | Checkout без имени | High | Заказ не оформляется, поле отмечено как обязательное |
| TC-WEB-008 | Проверка итоговой суммы | High | Итог равен сумме товаров и отображаемых начислений |

## Матрица трассировки

| Требование | Тест-кейсы | Статус выполнения |
| --- | --- | --- |
| REQ-WEB-01: пользователь может войти | TC-WEB-001, TC-WEB-002 | Выполнено: passed |
| REQ-WEB-02: пользователь управляет корзиной | TC-WEB-003, TC-WEB-004 | Выполнено: passed |
| REQ-WEB-03: пользователь оформляет заказ | TC-WEB-006–TC-WEB-008 | Выполнено: passed |

## Результаты

Все запланированные сценарии выполнены: фактический результат соответствует ожидаемому. В рамках текущего прогона дефекты не зафиксированы. Скриншоты и новые баг-репорты добавляются при повторном воспроизведении.
