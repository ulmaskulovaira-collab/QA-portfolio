# 05. Ручное тестирование: Web, API и SQL

Учебно-практический блок, который дополняет проекты по функциональному и регрессионному тестированию. Здесь собраны связанные артефакты: тест-дизайн, ручные проверки интерфейса, Postman-коллекция и SQL-валидация данных.

## Проекты

| Файл | Направление | Результат |
| --- | --- | --- |
| [saucedemo-web.md](saucedemo-web.md) | UI и пользовательский путь интернет-магазина | набор сценариев и ожидаемые результаты |
| [booking-api.md](booking-api.md) | REST API бронирований, Postman | набор сценариев и ожидаемые результаты |
| [sql-data-validation.md](sql-data-validation.md) | SQL-проверки качества данных | SQL-запросы для проверки |

## Инструменты

Chrome DevTools · Postman · Swagger · REST/JSON · SQL · PostgreSQL/SQLite · Git/GitHub

## Что демонстрирует раздел

- тест-анализ и декомпозицию пользовательского пути;
- позитивные, негативные и граничные проверки;
- проверку HTTP-кодов, структуры JSON и API-авторизации;
- проверку целостности данных SQL-запросами;
- понятную тестовую документацию без выдуманных дефектов.

Это учебные примеры проверок. Для Web и API в папке нет полного отчёта о фактическом прогоне; SQL-запросы требуют подходящей схемы базы. Готовый воспроизводимый SQL-проект — [заказы на SQLite](../06-order-data-tests/README.md).
